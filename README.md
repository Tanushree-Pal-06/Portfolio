# Tanushree's Dev Studio

Build my complete personal developer portfolio website from scratch.

IMPORTANT:
This should be a polished, visually distinctive PROFESSIONAL DEVELOPER PORTFOLIO.

It should NOT look like an online resume, a generic AI-generated portfolio template, or an overly futuristic/cyberpunk website.

The website should feel:
- Professional
- Modern
- Creative
- Personal
- Developer-focused
- Visually memorable
- Mature and clean

I want the design to have a strong visual identity while still looking appropriate for internships, software engineering roles, recruiters, and professional networking.

==================================================
1. TECHNOLOGY
==================================================

Build the frontend using:

- React
- JavaScript
- HTML
- CSS

Use Vite if appropriate.

Do not introduce unnecessary advanced technologies.

Do NOT use:
- Next.js
- Three.js
- WebGL
- Complex 3D systems

2. CORE VISUAL DIRECTION
==================================================

The overall theme should be DARK, but do NOT interpret "dark" as black + red.

I specifically want a beautiful, eye-friendly dark color palette.

Use a palette inspired by:

- Deep midnight navy
- Dark blue / blue-gray surfaces
- Warm off-white text
- Soft pastel lavender
- Muted pastel peach/coral
- Subtle cool blue accents

Suggested palette direction:

Background:
#0B1220 / similar deep navy

Surface:
#111C2E / similar dark blue-gray

Primary text:
Warm off-white

Primary accent:
Soft lavender / periwinkle

Secondary accent:
Muted pastel peach

These exact hex values can be adjusted slightly if needed, but maintain this overall visual direction.

The result should NOT look neon.

Avoid:
- Bright neon blue
- Neon purple
- Bright red
- Black-and-red combinations
- Excessive gradients
- Excessive glow effects

Use gradients only where they genuinely improve the visual design.
